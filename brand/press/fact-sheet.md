# Takes fact sheet

| | |
|---|---|
| **What it is** | A Mac menu-bar app that rewrites the draft in any text field a few ways and pastes back the one you pick |
| **Maker** | Bar Amir, an independent developer |
| **Price** | Free. No ads, no paid tier, no account |
| **License** | MIT (the code). The name, logo and icon are not covered by the license |
| **Current version** | 0.7.0 (8 November 2026) |
| **First release** | 0.1.0 (27 October 2026) |
| **Requirements** | macOS 14 or later, Apple silicon or Intel. Accessibility access to read the text field and paste |
| **Engines** | Claude Code with your Claude plan · Anthropic API key · your ChatGPT Plus or Pro plan (Sign in with ChatGPT) · your own key for OpenAI, Google Gemini, OpenRouter, Groq, Mistral or any OpenAI-compatible https server · Ollama or LM Studio on your Mac |
| **Privacy** | No server, no analytics, no crash reporting. The draft goes only to the engine you chose, from your Mac, under your account. With a local model it never leaves the Mac. Keys live in the macOS Keychain |
| **Built with** | Swift 6, SwiftUI and AppKit, the macOS Accessibility API, Sparkle for updates |
| **Distribution** | Signed with a Developer ID and notarized by Apple. Direct download or Homebrew (`brew install --cask bar-amir/tap/takes`) |
| **Key features** | 1 to 5 takes side by side · presets with Do and Avoid rules and examples of your writing · Proofread with marked fixes · tone notes · reply context · a preset hotkey that writes and pastes right away · dictation on the Mac · any language · an optional English coach |
